# VDMA

Приложение для изучения отрывков Писания (Синодальный перевод) по методу «Герменевтической спирали» и подготовки проповеди: структура отрывка, заметки к словам, пометки на тексте, текст проповеди блоками, показ слайдов, выгрузка в Word.

Открыть: https://dkloban-ctrl.github.io/razbor-slova/

- Синхронизация телефона и ноутбука: кнопка «Синхронизация» в библиотеке, данные хранятся в отдельном закрытом репозитории владельца (ключ доступа вводится на каждом устройстве).
- Данные хранятся в браузере устройства, на котором вы работаете. Резервная копия — кнопка «Скачать всю библиотеку», восстановление — «Загрузить библиотеку из файла».
- После первого открытия страница работает и без интернета; книги Библии сохраняются по мере того, как вы их открываете.
- Файл для показа в зале («Файл для зала») открывается с диска и не требует интернета.

Текст: Синодальный перевод, `bible/*.json`.
